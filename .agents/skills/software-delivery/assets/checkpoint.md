# Delivery checkpoint

Use only for a useful handoff or recovery. Keep the current state here; preserve history in Git and original artifacts. Update on a material event, not a timer.

- Outcome and acceptance:
- Scope, exclusions, and permissions:
- Current branch/worktree; baseline changes to preserve:
- Working result and completed checks:
- Evidence locations and identity: code/diff, configuration, environment/time, data snapshot where relevant:
- Current step and next concrete action:
- Blocker, affected work/claim, owner, and smallest resolution:

Do not record credentials or copy raw logs. Omit fields that do not help the next action. A checkpoint update alone is not a reason to create a commit.
